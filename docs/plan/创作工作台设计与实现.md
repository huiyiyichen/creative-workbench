# 创作工作台：设计与实现

总方案见 `创意工作台改造方案.md` 第 7 节（多 agent 与追溯见第 2.2、2.3 节，生图见第 7.4、8 节）；视觉沿用方向 A（`direction-a-grading.html`）。

## 1. 要解决的问题

| 现状 | 改法 |
|---|---|
| 一个 `/studio` 页面装下全部流程，状态靠 localStorage 恢复 | 以「项目」为单位，每一步一个路由，状态写在 URL 和后端 |
| 选题卡片无封面、信息少，难找 | 列表 + 详情的选题器，带封面、指标、摘要、相关内容，可搜索筛选 |
| 一个项目只能有一个来源 | 项目可挂多个来源，区分主来源和参考 |
| 成稿页设定、正文、整页 diff、分镜堆在一起 | 三栏：大纲 / 编辑器 / 侧面板；版本对比按需打开 |
| 每次保存都生成新版本、撤销定稿 | 自动保存写工作副本；只有「保存版本」、AI 成稿、定稿生成版本；制作参数移到产出物 |
| 修改要求只能整篇重写 | AI 修改以建议呈现，按段 / 按镜接受或拒绝 |
| 成片页和制作记录日志全部展开 | 产出物各有工作区；任务进度用阶段条，日志折叠 |
| AI 过程看不见，结果说不清从哪来 | AI 操作以流程运行，节点图实时显示；产物可溯源到段落、分镜和采集内容 |
| 只能出视频和提示词 | 产出物：小红书 / 知乎 / 公众号版本、一键成片、视频提示词包、MV |
| 创作时用不上收藏的图片和风格 | 情绪板放灵感库条目；用灵感作参考生图（6.5） |

## 2. 路由

| 路由 | 页面 |
|---|---|
| `/projects` | 项目列表 |
| `/projects/new?source=content:123` | 新建项目（来源可以是 `content:`、`library:`、或空） |
| `/projects/[id]/idea` | 第一步：选题与创意 |
| `/projects/[id]/draft` | 第二步：文稿 |
| `/projects/[id]/outputs` | 第三步：产出物列表 |
| `/projects/[id]/outputs/[outputId]` | 某个产出物的工作区 |
| `/tasks` | 任务中心（另有全局抽屉） |
| `/works` | 作品库 |
| `/runs/[id]` | 运行视图：节点图、时间线、调用树（见 7.1） |

旧的 `/studio` 重定向到 `/projects`；`/studio?project_id=36` 重定向到 `/projects/36/draft`。

## 3. 项目框架

所有步骤共用顶部的项目栏：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ ‹ 项目   每天 601 美元的编码智能体 ✎      [已定稿 v8 🔒]                   │
│          ① 选题与创意 ──── ② 文稿 ──── ③ 产出           任务 2  过程  版本 │
└────────────────────────────────────────────────────────────────────────────┘
```

- **标题**：可直接编辑；默认取主题，最长 120 字，超出省略，悬停显示全文。
- **状态标记**：草稿（灰）/ 已定稿 vN（白底，带锁）/ 有未保存修改（黄点）。
- **步骤条**：这里的编号是真实顺序，所以保留。
  - 文稿：需要先有主题才能进入。
  - 产出：未定稿时也能进入，页面中央提示「定稿后可制作」，并提供「去定稿」按钮。
- **任务**：显示本项目进行中的任务数，点击打开任务抽屉并只显示本项目的任务。
- **版本**：打开版本面板（见 5.6）。
- **过程**：列出本项目所有流程运行和人工决定；点一次运行打开节点图（见 7.1）。

**来源列表**
- 五个页签：灵感库（默认，含素材和随笔）、今日、热点、专题、手动输入。
- 条目行：封面缩略图（视频 16:9 / 竖版 9:16 缩略）、标题两行、平台与作者、一个主指标、已选标记。
- 筛选：形态、平台、时间（24 小时 / 7 天 / 30 天 / 全部）；搜索走后端全文检索，输入 300ms 后请求。
- 虚拟列表，每次加载 30 条，滚动到底继续加载。
- URL 带 `?source=content:123` 进入时，直接请求该条目，不依赖列表里是否已加载。

**详情面板**
复用全站的 `ContentDetail` 组件：结论与依据、封面 / 视频预览、指标示波、摘要或字幕摘录、相关内容、评论折叠区（默认收起）。

**已选来源**
- 每个项目可以有 1 个主来源和最多 9 个参考。
- 来源进入项目时冻结一份快照（标题、链接、平台、发布时间、采集时间、摘要、指标），之后原内容变化不影响项目。

**情绪板**
- 从灵感库拖入或选择图片、风格、提示词、随笔，最多 30 项；记为项目素材（role = moodboard）。
- 不参与来源快照和引用，只作为创意和生图的参考。
- 「生图」打开生图面板（6.5），参考默认取情绪板里选中的条目。

**创意方向**
- 点「AI 给出方向」：启动选题研究流程（研究员 → 策划），读取主题、已选来源、情绪板、创作思路，返回 3–5 张方向卡。方向区显示流程进度，点「查看过程」打开节点图。
  - 每张包含：标题、角度、适合的产出、依据的来源。
  - 点卡片：填入主题和创作思路。
  - 也可以在「自己写」卡片里直接输入。
- 未配置模型时，这个按钮换成「配置模型」链接，「自己写」照常可用。

**设定**（全部属于文案层）
主题、内容形态、时长（视频形态才显示）、受众、内容模板（打开风格 / 模板选择器，显示版本）、创作思路。

**开始写稿（三个按钮）**
- **空白开始**：只建空文稿。
- **按模板生成结构**：用模板的段落 / 分镜结构生成骨架，即现有 `compile_draft`。
- **AI 写初稿**：启动成稿流程（写手 → 审校 → 写手修改），进入文稿页，并显示流程进度。

**状态**
- 没有来源也没有主题：中央显示「从灵感库挑一条」和「直接写主题」两个按钮。
- AI 失败：在方向区内显示原因和「重试」，已填写的内容保留。

## 5. 第二步：文稿

```text
┌ 大纲 ────────┐┌ 编辑器（纸面） ──────────────────────────────┐┌ 侧面板 ───────────────┐
│ 文章：标题树 ││ 每天 601 美元：编码智能体的翻倍曲线           ││ [AI 助手][设定][版本][来源]│
│ 视频：分镜列表││ 梗概（一段）                                  ││                        │
│  1 钩子 0:08 ││ 正文……                                        ││ 修改范围：全文▾         │
│  2 口径 0:20 ││   ┃ 建议：把这句改成…  [接受][拒绝]          ││ [更口语][压缩到 600 字] │
│  3 翻倍 0:18 ││ 正文……                                        ││ [换个开头][加一个例子]  │
│  …           ││                                               ││ 指令输入框              │
│              ││                                               ││            [发送 Ctrl⏎]│
│ 总时长 2:51 / ││                                               ││ 历史：10:21 更口语 ✓   │
│ 目标 3:00    ││                                               ││       10:05 换个开头 ✕  │
└──────────────┘└───────────────────────────────────────────────┘└────────────────────────┘
┌ 底栏：1,284 字  预计朗读 3:05   已自动保存 10:32   [保存版本 Ctrl S]   [定稿]           ┐
```

### 5.1 编辑器

**文章形态**
- 编辑器使用 TipTap（ProseMirror）。正文存为 Markdown，与现有 `StudioDraft.body` 兼容。
- 标题单独一个输入区，可多行，不限制换行显示。
- 排版：纸面底色 `#eceee9`、墨色文字 `#1d2026`，Noto Serif SC，17px，行高 1.9，每行约 34 个汉字。
- 支持标题、引用、列表、粗体、链接、图片、来源引用标记。中文输入法组字期间不触发自动保存和 AI 建议定位。

**视频形态：脚本视图**
左右两个页签：

```text
[旁白全文]  [分镜表]
┌──┬──────┬──────────────┬──────────────┬──────────────┬──────────┬────┐
│镜│ 时长 │ 画面          │ 镜头与运动    │ 旁白          │ 字幕      │ ⋯  │
├──┼──────┼──────────────┼──────────────┼──────────────┼──────────┼────┤
│1 │ 0:08 │ 深色背景，…   │ 16:9 正中…    │ 先看一个数字…  │ 601 美元  │ ⋯  │
│2 │ 0:20 │ …             │ …             │ …              │ …         │ ⋯  │
└──┴──────┴──────────────┴──────────────┴──────────────┴──────────┴────┘
             总时长 2:51 ▕██████████████████████▏ 目标 3:00
```

- 每行可以拖动排序、插入、删除、复制。行菜单里有「改写这一镜」「拆成两镜」「合并到下一镜」。
- 「提示词」「衔接」两列默认折叠；点行展开后显示全部字段。
- 时长用 Bahnschrift 等宽数字。总时长条超出目标时显示为黄色。
- 「旁白全文」由各镜旁白按顺序拼接，可以直接编辑。编辑时按段落对应回分镜；段落数和分镜数不一致时，提示「按段落重新分镜」。

**MV 形态**
分镜表上方加一条歌词时间轴：音频波形（wavesurfer.js）+ LRC 歌词块。拖动分镜边界时吸附到歌词时间点；LRC 是歌词时间的唯一来源，AI 不改歌词。

### 5.2 大纲

- 文章：标题树，点击跳转到对应段落，拖动可调整章节顺序。
- 视频：分镜列表（序号、名称、时长），点击选中对应行。
- 底部：总字数或总时长 / 目标。

### 5.3 自动保存与版本

- **工作副本**：编辑后 1.5 秒自动保存到工作副本，不生成版本。底栏显示「已自动保存 10:32」，有未保存修改时显示黄点。
- **版本**：「保存版本」（Ctrl S）、AI 写初稿、接受 AI 建议后、定稿时各生成一个版本，并记录原因。
- **冲突**：自动保存带上次的 `draft_token`。若别的窗口已修改，返回 409；界面显示「这份文稿在另一个窗口改过」，给两个选项：「载入最新」，或「用我的覆盖」（覆盖前先把对方的内容存成一个版本）。

### 5.4 AI 助手（右侧面板第一个页签）

- **修改范围**：全文 / 选中的段落 / 选中的分镜。在编辑器里选中文字或分镜时，范围自动切换。
- **快捷指令**：更口语、更正式、压缩到 N 字、换个开头、加一个例子、按模板重排、补充来源依据。也可以输入自由指令，Ctrl+Enter 发送。
- **结果是一组建议**，不直接改文稿：
  - 编辑器里以修订样式显示：删除线 + 新文字，每处带「接受 / 拒绝」。
  - 面板顶部有「全部接受」「全部拒绝」。
  - 接受任意一处后生成一个版本，原因记为「AI 建议」。
- **历史**：列出每次指令的时间、范围、模型、结果（已接受 / 部分接受 / 已拒绝），点开可以重新查看那次的建议。
- **出错**：未配置模型时显示「配置模型」；超时或失败时显示原因，并提供「重试」。
- **审校意见**：成稿流程和每次 AI 修改后，审校的意见以批注显示在编辑器右边缘；没有出处的句子标黄；点批注可以「让写手按此修改」（生成一组新建议）或「忽略」。
- **引用**：写手产出的事实带引用标记 `[n]`，悬停显示原文摘录和来源；点「溯源」打开溯源图。

### 5.5 设定（右侧面板第二个页签）

内容形态、内容模板、受众、语气、时长、创作思路，全部属于文案层。已定稿时修改任一项，会弹窗说明「修改后需要重新定稿，已有作品保留」，提供确认和取消。

### 5.6 版本（右侧面板第三个页签，也可以从项目栏打开）

- 列表项：v8 定稿 10:40 / v7 AI 建议 10:21 / v6 保存版本 10:05……
- 点某个版本：只读预览。
- 「与当前对比」打开全屏对比：左右并排。
  - 文章按段落对齐，段内按字符高亮差异。
  - 分镜按镜对齐，逐字段比较。
  - 顶部有「上一处 / 下一处差异」，以及「恢复为这个版本」（恢复操作会生成新版本）。

### 5.7 来源（右侧面板第四个页签）

- 列出项目来源，点击展开 `ContentDetail` 的精简版。
- 「插入引用」：在光标处插入 `[1]`，正文末尾自动维护来源列表。
- 「插入摘录」：选中详情里的字幕或摘要文字，以引用块插入。

### 5.8 定稿

- 底栏点「定稿」，弹窗列出将锁定的内容（选题、内容形态、内容模板、受众、创作思路、时长、成稿），并说明「视觉风格、配音、画幅在产出里随时可改」。
- 定稿后：编辑器只读，顶部横幅显示「已定稿 v8」，带「继续修改」按钮。点击后解锁，下一次保存生成新版本，状态回到草稿；已有产出物标记为「基于 v8」。
- 快捷键：Ctrl S 保存版本；Ctrl Enter 发送 AI 指令；Alt ↑/↓ 移动当前分镜。

- **新建产出**菜单：小红书版、知乎版、公众号版、讲解视频（一键成片）、视频提示词包、音乐 MV。
- **未定稿时**：只能新建平台版本的草稿；视频、MV、提示词包的「开始」按钮不可用，并提示「定稿后可制作」。
- **产出物卡片**：类型、状态（草稿 / 制作中 / 完成 / 失败 / 已导出 / 已发布）、基于的版本、关键信息（时长、字数）。
- **文稿有新定稿版本时**，卡片显示「文稿已更新到 v9」，点击可以基于新版本重新生成。

### 6.1 平台版本（小红书 / 知乎 / 公众号）

- **生成**：从定稿改写，平台规则写在配置里：

| 平台 | 规则 |
|---|---|
| 小红书 | 标题 ≤20 字；正文 ≤1000 字；话题 3–8 个；封面文案 ≤12 字；配图建议 3–9 张 |
| 知乎 | Markdown；小标题分节；文末列出来源 |
| 公众号 | 标题、摘要 ≤120 字、正文 HTML（只允许 p、h2、h3、strong、em、blockquote、ul、ol、li、img、a）、封面 |

- **编辑**：左边编辑器，右边平台预览。
  - 小红书：手机外框、标题字数计数、话题标签。
  - 知乎：文章页样式。
  - 公众号：文章页，可切换排版主题。
- **导出**：复制标题、复制正文、复制话题、导出 Markdown、导出 HTML、打开发布页。
- **发布状态**：发布后可以填入发布链接，状态变为「已发布」；之后可以把这个链接当作信源采集它的数据。
- **安全**：模型返回的 HTML 经白名单清洗后保存；预览放在 sandbox iframe 中，不执行脚本。

### 6.2 讲解视频（一键成片）

- **制作参数（制作层）**：视觉风格（风格选择器，带色板预览；可输入名称让 AI 生成，见方案 6.6）、表现方案、画幅、配音（音色、试听）、中英字幕卡。修改参数不影响定稿。
- **素材**：可勾选项目素材里的图片、分镜关键帧、配乐放进成片；授权为「仅参考」「未知」的显示提醒。
- **执行者**：制作这一步可选 DeepSeek Harness（默认）、Claude Code、Codex。
- **开始制作**：启动讲解视频流程（分镜 → 美术出关键帧 → 制作 → 质检）。工作区显示每个节点的阶段条（制作内部：配音 → 设计 → 编译检查 → Remotion 渲染 → 整理），以及当前阶段的百分比和耗时；点「查看过程」打开节点图。
- **质检**：完成后显示质检报告（时长、字幕对齐、黑帧、静音、与分镜不符的镜头）；不通过时自动退回制作，最多 2 次，仍不通过则停下并列出问题。
- **完成后**：播放器预览；可以下载 MP4、工程 ZIP、SRT / ASS 字幕，或加入作品库；点「溯源」查看成片用到的分镜、文稿版本、素材和来源。
- **历史成片**：列出每次制作的序号、版本、风格、结果；点击查看当时的参数；失败的可以一键重试，可复用的设计源码会自动复用。

### 6.3 视频提示词包

- **目标**：通用 / Claude Code / Codex / DeepSeek Harness，影响格式和交付说明的写法。
- **内容勾选**：定稿脚本、分镜表、风格规范（色板、字体、构图、动效）、素材清单（音频、LRC、参考图、关键帧，含授权状态）、交付要求（画幅、时长、字幕、输出格式）。
- **预览与导出**：右侧实时预览生成的 Markdown；可以复制、下载 `.md`，或下载 `.zip`（含素材）。
- **外部 agent 接入**：显示工作台工具的连接地址和项目 id；外部 agent 做完后，可以在「回传成片」里上传，也可以由 agent 通过工具上传。
- 提示词包由模板确定性生成，不调用模型；可选「润色提示词」时才调用模型。

### 6.4 音乐 MV

- 上传音频，粘贴或上传 LRC，在时间轴上校对歌词。
- 之后与讲解视频相同：设制作参数 → 开始制作；也可以导出提示词包。

│ 参考  [海报 ✓] [海报 ✓] [包豪斯 风格 ✓] [+ 从灵感库]                            │

│ ┌──────────────────────────────────────────────────────────────────────────┐   │
│ │ 几何色块构成的时间轴，红黄蓝与黑白，无衬线大字「601 美元」……             │   │
│ └──────────────────────────────────────────────────────────────────────────┘   │
│ 服务 [image2.5 ▾]  尺寸 [3:4 ▾]  张数 [4]                         [生成]       │
│ ┌────┐┌────┐┌────┐┌────┐                                                       │
│ │ ✓  ││    ││    ││    │   [出变体] [以此为参考再生成] [存入并使用]            │
│ └────┘└────┘└────┘└────┘                                                       │

- **入口与目标**：情绪板（无目标）、文稿插图位置（段落 id）、小红书配图（第 N 张）、公众号封面、分镜关键帧（分镜序号）、MV 画面（歌词时间点）。目标决定默认尺寸和插入位置。
- **参考**：默认取情绪板里选中的条目，可以从灵感库追加；风格的规则写进提示词，图片在服务支持参考图时作为输入，不支持时只用其 AI 描述。
- **提示词起草**：读取目标处的文稿段落或分镜画面描述、所选风格版本、参考条目的描述，生成提示词草稿，可直接修改。

- **存入并使用**：选中的结果作为「生成图」写入灵感库（授权「AI 生成」，记录提示词、模型、参数、参考条目），同时加入项目素材并放到目标位置。没选中的候选保留 7 天。
- **出变体 / 以此为参考再生成**：以选中的图作为参考，沿用提示词，生成新一组候选。
- **花费**：每次生成显示预计花费和当日已用额度；超过生成服务的每日上限时提示。

## 7. 任务中心

- **全局抽屉**：右上角「任务」按钮显示进行中的数量；抽屉按「进行中 / 失败 / 完成」分组。
- **任务行**：类型图标、项目名、产出物名、阶段条、耗时、花费、状态。
- **展开后**：阶段时间线（每个阶段一行，带开始时间和耗时）；原始日志放在「查看日志」里，默认折叠。
- **失败**：写明发生了什么、怎么处理，例如「DeepSeek 设计超过 10 分钟，已停止。可重试，已生成的源码会复用」。提供「重试」「打开工作目录」。
- **流程运行**：点开进入运行视图（7.1），可以「停止」。
- **实时更新**：用 SSE（`/api/v1/tasks/stream`）推送，替代现在的定时轮询；任务完成时弹出通知。
- `/tasks` 页面：完整列表，可按项目、类型、状态、时间筛选。

│  ┌────────┐     ┌────────┐     ┌────────┐     ┌────────┐               │

### 7.2 溯源图

- 所有产物（文稿段落、分镜、生成图、成片、平台稿）都有「溯源」入口，打开为抽屉。

生成记录使用方案第 8 节的 `generation_jobs`，以 project_id、output_id 关联。

流程运行与溯源使用方案第 2.3 节的 `agent_runs`、`agent_steps`、`trace_spans`、`artifacts`、`artifact_links`、`decisions`。`studio_revisions` 的每个版本、`studio_outputs` 的平台稿、`studio_artifacts` 的成片都登记为产物。

### 10.3 `studio_artifacts`（保留）

新增 `output_id`（外键到 `studio_outputs`）和 `settings`（本次制作使用的制作层参数快照）。

### 10.4 迁移

1. **项目**：每个现有项目把 `spec.brief` 里的制作层字段（style_id、presentation、production、aspect_ratio、bilingual）移到一个新建的「视频」产出物的 `settings`。
2. **作品**：现有 artifacts 的 `output_id` 指向这个产出物；`settings` 从当时版本的修订快照中补齐。
3. **来源**：`source_snapshot` 转成一条 `project_sources`（role = main）。
4. **工作副本**：`draft_token` 初始化为当前 `updated_at`。
5. **回滚**：降级迁移删除新列和新表；旧字段在迁移中只读不删，降级后照常可用。

## 11. 接口

前缀 `/api/v1`。错误统一为 `{code, message, details}`：

| 状态码 | code | 场景 |
|---|---|---|
| 409 | `draft_conflict` | 附当前 token |
| 422 | `validation_error` | 附字段错误 |
| 503 | `model_not_configured` / `model_unavailable` | 模型未配置或不可用 |

**项目**
- `GET /projects?stage=&q=`、`POST /projects {theme?, sources?}`、`GET /projects/{id}`、`PATCH /projects/{id} {title}`、`POST /projects/{id}/archive`

**来源**
- `POST /projects/{id}/sources {content_id | library_item_id, role}`、`DELETE /projects/{id}/sources/{sid}`、`PATCH /projects/{id}/sources/{sid} {role}`

**创意**
- `POST /projects/{id}/directions` → `[{title, angle, outputs[], basis_source_ids[]}]`
- `PUT /projects/{id}/brief {brief, draft_token}`：文案层设定；已定稿时返回 409 `finalized`，需要先调用解锁

**文稿**
- `GET /projects/{id}/draft` → `{brief, draft, template, draft_token, version, finalized_version, dirty}`
- `PUT /projects/{id}/draft {draft, draft_token}` → `{draft_token}`：自动保存
- `POST /projects/{id}/draft/generate {mode: blank | template | ai}` → 任务 id（ai 模式），或直接返回文稿
- `POST /projects/{id}/versions {reason}`、`GET /projects/{id}/versions`、`GET /projects/{id}/versions/{v}`、`POST /projects/{id}/versions/{v}/restore`
- `POST /projects/{id}/finalize {version}`、`POST /projects/{id}/unlock`

**AI 建议**
- `POST /projects/{id}/suggestions {scope, instructions, draft_token}` → `{id, ops[]}`
- `POST /suggestions/{id}/apply {op_ids[]}` → 新的 draft、draft_token、version
- `POST /suggestions/{id}/reject`
- `GET /projects/{id}/suggestions`

**产出物**
- `GET /projects/{id}/outputs`、`POST /projects/{id}/outputs {kind}`、`GET /outputs/{id}`、`PATCH /outputs/{id} {content | settings | published_url}`
- `POST /outputs/{id}/generate`：平台改写，返回任务 id
- `POST /outputs/{id}/render`：视频 / MV 制作，返回任务 id
- `GET /outputs/{id}/bundle?format=md|zip`
- `POST /outputs/{id}/assets`：音频、LRC、回传成片

**素材与生图**
- `GET /projects/{id}/assets`、`POST /projects/{id}/assets {library_item_id, role, target?}`、`DELETE /projects/{id}/assets/{aid}`
- `POST /generations/images {project_id?, output_id?, target?, prompt, ref_item_ids[], size, n, provider_id}` → 任务 id
- `POST /generations/{id}/keep {indexes[], role}`：选中的结果存入灵感库并加入项目素材
- `POST /projects/{id}/image-prompt {target, style_version_id?, ref_item_ids[]}` → 生成提示词草稿

**流程运行与溯源**
- `POST /runs {flow, project_id, params}` → 运行 id；`GET /runs?project_id=&flow=&status=`
- `GET /runs/{id}`：图结构（节点、边）、步骤状态、预算与花费；`GET /runs/{id}/stream`（SSE）
- `GET /steps/{id}`、`GET /spans/{id}/payload`（按需加载提示词、回复、工具参数与结果）
- `POST /runs/{id}/gates/{gate} {choice}`：在人工关卡上做选择；`POST /runs/{id}/stop`
- `POST /steps/{id}/rerun {prompt?, model?, executor?}` → 分叉运行 id；`GET /steps/compare?a=&b=`
- `GET /artifacts/{id}/lineage?direction=up|down&anchor=`、`GET /contents/{id}/journey`

**任务**

## 12. 后端实现

**服务拆分**（沿用 `api → services → repositories → models`）

| 服务 | 职责 |
|---|---|
| `project_service` | 项目、来源、快照 |
| `draft_service` | 工作副本、版本、定稿 / 解锁、文案层字段校验 |
| `idea_service` | 创意方向（LLM，结构化输出） |
| `suggestion_service` | 生成建议补丁、校验、应用 |
| `output_service` | 平台改写、HTML 清洗、提示词包 |
| `production_service` | 包装现有 `studio_remotion`、`studio_media`、`studio_tts`、`studio_subtitles`，读取「定稿文案 + 产出物 settings」 |
| `task_service` | 统一任务记录、进度事件、SSE 推送、重试、取消 |
| `project_asset_service` | 情绪板与项目素材、授权提醒 |
| `generation_service` | 调用方案第 8 节的生成服务适配器；提示词草稿；结果落盘并写入灵感库 |
| `flow_service` | 加载 YAML 流程模板、编译为 LangGraph 图、启动 / 恢复 / 分叉运行、处理人工关卡 |
| `agent_adapters/` | 内部模型、DeepSeek Harness、Claude Code（Agent SDK）、Codex（`codex exec --json`）四个执行者，事件统一转换 |
| `trace_service` | 写入步骤与调用树、载荷压缩落盘与脱敏、产物登记与来源关系、溯源与经历查询 |

**建议补丁格式**
- 段落在保存时获得稳定 id（`p_` + 内容哈希的前 8 位，冲突时追加序号）。
- 操作类型：`replace_paragraph(id, text)`、`insert_after(id, text)`、`delete_paragraph(id)`、`update_shot(index, field, value)`、`insert_shot(after, shot)`、`delete_shot(index)`、`move_shot(from, to)`。
- 模型按 JSON Schema 返回操作列表；服务端校验 id 存在、字段与长度边界（沿用 `StudioShot` / `StudioDraft` 的上限）、操作数 ≤50。
- `apply` 时检查 `base_token` 与当前 token 一致。不一致时，只应用目标段落未被修改过的操作，其余标记为冲突返回。

**平台改写**
- 平台规则放在 `output_rules.py` 配置。
- 模型返回结构化字段（title、body、tags、cover_text、image_suggestions），超出字数时返回给模型重写一次，再超出则截断并提示。
- 公众号 HTML 用 `nh3` 按白名单清洗。

**提示词包**
- 用 Jinja2 模板，由定稿版本、产出物 settings、风格版本、素材清单渲染。
- ZIP 包含 `README.md`、`script.md`、`storyboard.csv`、`style.json` 和素材文件。

**任务进度**
- 现有 `_progress` 写库的同时，发布到进程内事件总线。
- SSE 端点按任务或项目订阅；断线重连时先补发最近状态。

**文案层校验**
`draft_service.copy_layer_changed(old_brief, new_brief, old_draft, new_draft)` 比较文案层字段和成稿；只有变化时才要求解锁。

## 13. 前端实现

- **页面结构**（Next.js App Router）：`app/projects/page.tsx`、`app/projects/[id]/layout.tsx`（ProjectShell）、`idea/page.tsx`、`draft/page.tsx`、`outputs/page.tsx`、`outputs/[outputId]/page.tsx`。
- **服务端状态**：TanStack Query（缓存、失效、乐观更新）。
- **自动保存**：`useAutosave(draft, token)`，防抖 1.5 秒；串行发送；收到 409 时进入冲突状态。
- **新增依赖**：`@xyflow/react`（节点图）、`@tanstack/react-query`、`@tiptap/react` 与 starter-kit、`tiptap-markdown`、`@dnd-kit/core`、`@dnd-kit/sortable`、`wavesurfer.js`、`diff-match-patch`。
- **对比**：段落对齐先按段落 id 匹配，再用 diff-match-patch 比较段内文字。
- **无障碍**：所有操作可用键盘完成；任务更新使用 `aria-live="polite"`；分镜表可用方向键移动单元格。

**浏览器实测（桌面）**
1. 从今日的一条视频新建项目，确认封面和指标显示。
2. AI 给出方向 → 选择 → AI 写初稿。
3. 编辑后刷新页面，内容仍在。
4. 选中一段发送「更口语」，只接受其中一处。
5. 定稿；在产出里更换视觉风格并开始制作；成片使用的是定稿文案。

7. 导出提示词包 ZIP，检查文件齐全。
8. 任务失败后重试；设计源码被复用。
9. 情绪板加入两张收藏图，在小红书版里生成配图；选中一张后出现在灵感库，带提示词和参考条目。
10. 跑一次讲解视频流程：节点图实时更新；点成片「溯源」能逐层追到文稿段落和采集内容。
11. 在分镜节点换模型重跑，节点图出现分叉，「对比」并排显示两版分镜。
